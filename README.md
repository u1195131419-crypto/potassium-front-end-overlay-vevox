# Vevox

ive made a front end overlay for potassium as some side project, it looks like an executor but the back end of it just communicates with potassium.

## download
You can download the latest `.exe` release directly from the **[Releases Page](https://github.com/u1195131419-crypto/potassium-front-end-overlay-vevox/releases/latest)**.

## How it works
Vevox communicates with Potassium, if you click the Bridge setup tab, and click install it will put lua code into your potassium autoexec file to communicate with it.

## how to use it
Use the bridge setup in the app open potassium anc click attach, you can minimise potassium now (DONT CLOSE IT) and open Vevox. Vevox now acts as a fully working executor.
